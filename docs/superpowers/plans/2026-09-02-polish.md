# Polish-batch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mobiele navigatie (3a), doing-bevestiging (3b), intake-anker (3c), veroudering (2a-rest), aankomst-choreografie (2h minimaal) en de geparkeerde kleintjes — de laatste geplande ronde.

**Architecture:** Server levert één nieuwe afleiding (`open_requests` op verrijkte kaarten) en één extra cursorcomponent; al het overige is UI-werk op de bestaande machinerie (overlay, chips, poller-guards). Geen schemawijzigingen, geen nieuwe event-kinds.

**Tech Stack:** TypeScript core/Hono, vanilla-JS UI, Playwright-verificatie.

**Spec:** `docs/superpowers/specs/2026-09-02-polish-design.md` (design-artboards 3a/3b/3c + 2a/2h in `docs/design/Agentboard.dc.html`).

## Global Constraints

- Geen nieuwe event-kinds; het intake-anker leidt af uit bestaande comments/events (spec §3).
- De UI claimt niets dat hij niet weet: geen "next scheduled session"-tijden, alleen afleidbare liveness (spec §2).
- Bestaande gedragscontracten onaangetast: dirty-guards, overlay-guard (cursor niet advancen bij suppressie), busy-flag over de hele awaited keten, append-only tail.
- Verificatie: wegwerp-`AGENTBOARD_DATA`, fake `AGENTBOARD_SESSION_CMD` in dezelfde shell-invocatie, nooit `AGENTBOARD_AUTORUN`, serve killen; screenshots naar `docs/design/verify/polish/` en zelf BEKIJKEN vóór commit. Scroll-/inputbewijzen met echte input (`page.mouse.wheel`, `page.keyboard`), niet met dispatched events.
- Engels (UI-copy en comments), chirurgisch, NEW commits only — never amend.

In `enrichCardsIn` (regel ~141), na de `waits`-regel, de afleiding — zelfde semantiek als de intake in card.js (body + agent-comments met een `secret_ref:`-regel, open = nooit gestord óf opnieuw gevraagd ná de laatste store):

```ts
  // Open secret requests (design 3c): same derivation the card view uses —
  // names asked in the body or an agent comment's `secret_ref:` line count
  // as open until a secret_stored event newer than the newest ask exists.
  // Only ops cards still in play can have an intake, so only they get > 0.
  const SECRET_LINE = /^secret_ref:\s*(.+)$/m;
  const parseNames = (text: string | null) =>
    (text?.match(SECRET_LINE)?.[1] ?? '')
      .split(',')
      .map((s) => s.trim().toLowerCase())
      .filter(Boolean);
  const openRequests = new Map<string, number>();
  for (const card of cards) {
    if (card.type !== 'ops' || card.status === 'done' || card.status === 'archived') continue;
    const askedAt = new Map<string, string>();
    for (const n of parseNames(card.body)) askedAt.set(n, card.created_at);
    const comments = db
      .prepare("SELECT body, created_at FROM comment WHERE card_id = ? AND author = 'agent' ORDER BY id")
      .all(card.id) as { body: string; created_at: string }[];
    for (const c of comments) for (const n of parseNames(c.body)) askedAt.set(n, c.created_at);
    if (askedAt.size === 0) continue;
    const stored = db
      .prepare("SELECT payload, created_at FROM event WHERE card_id = ? AND kind = 'secret_stored'")
      .all(card.id) as { payload: string; created_at: string }[];
    const storedAt = new Map<string, string>();
    for (const e of stored) {
      const n = String((JSON.parse(e.payload) as { name?: string }).name ?? '').toLowerCase();
      const prev = storedAt.get(n);
      if (!prev || e.created_at > prev) storedAt.set(n, e.created_at);
    }
    let open = 0;
    for (const [n, asked] of askedAt) {
      const st = storedAt.get(n);
      if (!st || asked > st) open += 1;
    }
    if (open > 0) openRequests.set(card.id, open);
  }
```

en in de return-map: `open_requests: openRequests.get(card.id) ?? 0,`.

async function confirmDoingMove(card, onDone) {
  let liveLine = '';

  el.querySelector('#doing-cancel').onclick = closeOverlay;
