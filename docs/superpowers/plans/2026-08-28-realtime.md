# Realtime (bouwblok 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eén goedkoop `GET /api/changes`-kanaal (samengestelde versie-cursor) + een 2,5s-poller in de app-shell die elke view live houdt — met de bestaande dirty/overlay-guards als poort, een highlight-pulse op verplaatste kaarten, en de "overdue"-copy in de routines-modal.

**Architecture:** `changesSince()` in core (drie MAX-queries), passthrough-route, één poller in `app.js`. Kaartdetail behoudt zijn fingerprint/dirty-machinerie maar krijgt zijn signaal voortaan van de globale poller (interne 30s-timer vervalt). Geen schemawijzigingen.

**Tech Stack:** TypeScript core/Hono, vanilla-JS UI, Playwright-verificatie.

**Spec:** `docs/superpowers/specs/2026-08-28-realtime-design.md` (vision besluit K incl. amendement 2026-08-28).

## Global Constraints

- Cursor is opaque voor de client; alleen de server bouwt/vergelijkt hem. `changed` = `since` meegegeven én ongelijk aan de huidige cursor.
- De poller ververst NOOIT terwijl een overlay open staat of (op kaartdetail) de dirty-guard actief is; hij pauzeert bij `document.hidden` en tikt direct bij weer zichtbaar worden.
- Fouten in de poll zijn stil; de volgende tick probeert opnieuw. Eén tick tegelijk (busy-flag).

**Files:**

**Interfaces:**
- Produces: `changesSince(since?: string): { cursor: string; changed: boolean }`; `GET /api/changes[?since=]`; `api.changes(since)`.

- [ ] **Step 1: Core** — in `src/core/cards.ts`, na `gateWork`:

```ts
// One cheap question for the UI poller (vision besluit K, amended): did
// anything change? Events alone are too narrow — card creation and edits
// only touch card.updated_at, and comments are not events. The cursor is
// opaque to clients; any advance changes the string.
export function changesSince(since?: string): { cursor: string; changed: boolean } {
  const db = openDb();
  try {
    const e = (db.prepare('SELECT MAX(id) AS m FROM event').get() as { m: number | null }).m ?? 0;
    const c = (db.prepare('SELECT MAX(id) AS m FROM comment').get() as { m: number | null }).m ?? 0;
    const u = (db.prepare('SELECT MAX(updated_at) AS m FROM card').get() as { m: string | null }).m ?? '';
    const cursor = `e${e}.c${c}.u${u}`;
    return { cursor, changed: since !== undefined && since !== cursor };
  } finally {
    db.close();
  }
}
```

- [ ] **Step 2: Route** — in `src/api/server.ts` (import `changesSince`), bij de andere GET-routes:

```ts
  app.get('/api/changes', (c) => {
    try {
      return c.json(changesSince(c.req.query('since') || undefined));
    } catch (err) {
      return errorResponse(c, err);
    }
  });
```

- [ ] **Step 3: api.js**

```js
  changes: (since) => req(`/api/changes${since ? `?since=${encodeURIComponent(since)}` : ''}`),
```

- [ ] **Step 4: Verify (curl-matrix)** — init wegwerp-dir, serve op vrije poort:
1. `GET /api/changes` → `{cursor, changed:false}`; zelfde cursor als `since` → `changed:false`.
2. Kaart aanmaken (geen event!) → cursor beweegt, `changed:true` t.o.v. oude.
3. `card move` (event) → beweegt. 4. `card comment` (comment) → beweegt. 5. `card edit --labels x` (alleen updated_at) → beweegt.
Elke stap: nieuwe cursor ≠ vorige, en `changed:true` met de vorige als `since`. Serve killen.

- [ ] **Step 2: app.js — de poller.** Import `pokeCardRefresh` erbij uit `./views/card.js`. Na `window.addEventListener('hashchange', route); route();`:

```js
// --- realtime (vision besluit K): one cheap poll drives every view ---
let cursor = null;
let ticking = false;
async function tick() {
  if (document.hidden || ticking) return;
  ticking = true;
  try {
    const res = await api.changes(cursor ?? undefined);
    const changed = cursor !== null && res.changed;
    cursor = res.cursor;
    if (!changed) return;
    const overlay = document.getElementById('overlay');
    if (overlay && !overlay.hidden) return; // never yank an open dialog away
    if (parseRoute().name === 'card') pokeCardRefresh();
    else await route(); // cheap full re-render; overlay is closed, so no loss
  } catch {
    /* server hiccup — next tick retries */
  } finally {
    ticking = false;
  }
}
setInterval(tick, 2500);
document.addEventListener('visibilitychange', () => {
  if (!document.hidden) tick();
});
```
